# Domain types behavior

Status: Approved

Implementation status: Implemented for the behavior described below. This describes current code; intended requirements remain in the [English product specification](../../spec/evidence-trace-spec.md).

## Purpose

Shared record types, enum serialization, opaque identifiers, and UTC helpers.

## Responsibilities

Provide values exchanged by services and adapters.

## Not responsible for

Persist records, enforce investigation workflows, or render UI.

## Main features and rules

Services exchange typed records; enum strings are persisted and used in archives. IDs and timestamps are generated by shared helpers.

## Dependencies and interfaces

C++ standard library.

`domain/types.hpp`: records and conversion/helper functions.

Source: [implementation](../../../src/domain/types.hpp). See [tests](../../development/tests.md) for verification commands and limitations. Source inspection does not imply that every workflow was executed. [Technical notes](tech_notes.md) record constraints before changes.
