# MSP — Master Context & System Prompts for Evidence Trace

Ця директорія містить повний пакет знань, інструкцій та специфікацій для швидкого запуску роботи з будь-яким ШІ-асистентом (ChatGPT, Claude, Cursor, Antigravity, Codex).

---

## Вміст папки `MSP/`

1. **[`MSP.md`](MSP.md)** — **Master System Prompt (MSP)**
   * Головний системний промпт для ШІ-агента.
   * Містить усі правила, стек C++20/Qt6/SQLite, міграції (Схема v4), архітектуру сховища вкладень і хэшування SHA-256.
   * **Спеціальний протокол:** детальний опис того, що саме робити за командою:
     > **«у мене є msp для Evidence роби мені все про людину»**
   * Описує модель багатоідентифікаторної сутності `Person` (`identifier_for`), досьє `EntityProfilePage`, вставку фото з буфера (`Ctrl+V`), 6 вкладок профілю та команди збірки й перевірки.

2. **[`SPECIFICATION.md`](SPECIFICATION.md)** — **Master Specification**
   * Повна технічна специфікація реального стану репозиторію Evidence Trace.
   * 750+ рядків детального опису: функціональні вимоги, точна схема БД, діаграми станів, таблиці обмежень, матриця критеріїв приймання (AC-01 – AC-18) та інвентар функціоналу.

---

## Як використовувати будь-де

Коли ви відкриваєте нову сесію з ШІ, просто скопіюйте текст із [`MSP.md`](MSP.md) або вкажіть файл у контексті та скажіть:

> **«у мене є msp для Evidence роби мені все про людину»**

ШІ одразу отримає весь необхідний контекст без зайвих запитань і почне реалізовувати або доопрацьовувати функціонал для сутності **Людина (`Person`)**.
